# 内网 AI 服务接入调研（历史方案）

本记录整理 2026-10-08 的接入调研。它不是当前部署清单；后续 ASR 对齐、OCR、生图与视频适配已经演进，实际支持范围和迁移方法以 [媒体适配器维护文档](media-adapters.md) 为准。

个人机器地址、主机名、配置和本地调研文件不纳入仓库。本页仅保留可复用的设计结论，不宣称当前服务健康、模型身份或生成质量已验证。

## 能力与边界

| 能力 | 调研结论 | 接入边界 |
| --- | --- | --- |
| Qwen ASR | 早期接口仅返回转写文本 | 无时间戳的结果不能冒充字幕对齐；需要独立的真实对齐能力 |
| OCR | 抽取文字、坐标与置信度 | 不替代图片语义理解；图片方向、缩放和抽帧需保留坐标映射 |
| Qwen Image | 早期通过 ComfyUI 工作流生成 | 不能仅替换 OpenAI 接口地址；尺寸、编辑、遮罩等能力逐项核验 |
| H3 视频 | 工作流支持生成与参考素材 | 不同任务分别映射；带音轨不代表台词准确或逐字对齐 |

## 共用设计

- 共享技能入口调用统一媒体适配层；服务协议与专有参数集中于独立适配器。Web、CLI 和视频 SDK 复用同一接口。
- 实例配置保存在用户配置目录，凭证独立引用，不继承聊天模型的 Key。显式选择优先于默认；失败不自动切换付费服务或本地模型。
- 异步作业保存任务 ID、输入摘要和工作流版本。已知 ID 的任务查询与恢复不重复提交；提交结果未知时先核查远端，不自动重发或清空全局队列。
- 输出验证包括可解码性、尺寸、时长和完整性；内容质量需要单独验收，HTTP 200 不代表完成或质量通过。
- 文本识别与时间轴质量分开报告；不按文字长度伪造逐词对齐。
- 配置检查、服务健康、接口兼容、真实任务与人工质量判断分别报告，不相互替代。
- 大素材限制大小并使用受控临时文件；保留用户原件，不擅自截断。输入、凭证及个人网络拓扑不写入 Git。

## 验证顺序

1. 离线检查配置、协议映射、路径约束与错误处理。
2. 在实际运行机器核验服务连接；不根据另一台主机的连通性推断本机可达。
3. 经授权用固定本地样本验证识别、生成和对齐，记录真实输出及限制。
4. 验证断线恢复、重复提交防护和完整性，再更新相关技能说明与运行实例。

当前接口、使用示例及后续验收记录统一维护在 [媒体适配器维护文档](media-adapters.md)，本页不重复维护部署参数。
