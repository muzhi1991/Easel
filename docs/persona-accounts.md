# 画像、对话与平台账号

侧栏默认只列出当前画像的对话，通用模式也有自己的列表。「显示所有画像对话」可临时查看全部，切换画像后恢复筛选。对话的「复制或移动到画像」保留消息、附件引用和产物链接；复制保留原对话，移动用新对话替代原记录。运行中的对话必须先停止。

每个画像在每个平台使用一套独立登录态。账号页、发布中心、创作数据和画像页取数都跟随当前画像。通用模式保留升级前的登录态和公众号凭证；其他画像不会借用它。未登录的画像需要先在账号页登录。用户数据不提交 Git。

## 实现与兼容

- 复用会话已有的 `persona` 字段，不增加画像数据库或账号选择表。画像名称经 SHA-256 派生目录标识，避免将名称直接拼入文件路径。
- `easel/account_scope.py` 统一解析账号作用域。Web 使用请求级 ContextVar；子进程通过 `EASEL_ACCOUNT_PERSONA` 继承，不修改父进程环境。空值表示通用模式。
- 通用模式沿用原路径；命名画像在原浏览器、登录、数据历史和发布状态目录下使用 `personas/<标识>/`。公众号官方 API 凭证放在对应私有浏览器目录的 `wechat-publisher.yaml`，仍沿用 `accounts.web` 格式。B站 Cookie 同样保存在私有目录，不进入可下载的产物目录。
- 复制/移动使用数据库事务与版本校验，创建新的 Agent 会话，避免继续旧画像的运行时。完整可见历史保留，首次续聊把最近最多 80,000 字符的历史作为背景传入，明确历史中的发布要求不是新的授权。原消息里的附件引用继续由会话归属校验。
- 原有账号接口不带 `persona` 参数时仍表示通用模式。命令行独立使用时也保留原默认行为；指定 `EASEL_ACCOUNT_PERSONA` 后按画像隔离。作用域已经指定时，旧 `--profile-base` 参数不能覆盖它。

这是本机账号路由，不能隔离有任意本机代码执行权限的恶意程序。正常发布必须使用项目发布技能；不能绕过它改用外部浏览器的共享登录态。

## OpenClaw 接线

原生执行引擎从 Web 子进程环境接收画像。OpenClaw 常驻网关不继承每轮 Web 的环境，因此使用独立的轻量插件 [account-scope](../agents/account-scope/README.md)，通过官方 `resolve_exec_env` 钩子给每次 exec 设置画像。它不依赖工具预算插件，不修改 OpenClaw 安装包。

部署时在 Easel 专用 profile 的插件配置里添加 `agents/account-scope` 的绝对路径，启用 `easel-account-scope`，保留已有插件设置；有 allow 列表时也加入该插件。网关必须由项目入口启动，使 `EASEL_ROOT` 指向运行仓库。确认无生成中的对话后重启网关与 Web，并检查该插件实际加载了 `resolve_exec_env`。

Web 每轮及 Easel CLI 创建会话时写入 `outputs/_sessions/account-scopes/` 中的会话归属；插件读取它，不从模型参数猜测账号。缺失或损坏的归属让账号脚本拒绝执行，不回退通用账号。此时应从 Easel Web 重试。子 Agent 没有自动继承会话归属，账号相关操作应由当前对话执行。

升级时仅同步本次改动涉及的发布脚本与技能材料，保留现有账号文件；不要运行会重置记忆的完整 Agent 同步。工作流与回退遵循 [Fork 维护流程](fork-maintenance.md)。
